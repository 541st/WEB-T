; Название данного проекта - Сайт компьютерного клуба
; Приложение предназначено для регистрации постоянных клиентов. Для удобства, на сайте будет основная информация для привлечения новой аудитории, и удобный функционал для того, чтобы забронировать нужное количество ПК на нужное время.
; Сайт нужен для постоянных клиентов-геймеров и тех, кому внезапно требуется устройство для выхода в интернет, чтобы те смогли узнать все нужное себе.
; Ключевой функционал - регистрация пользователя для брони на нужное время, просмотр прайс-листа и основной информации.

;  Структура веб-приложения:
    Главная (/)
    Аутентификация /auth
    Каталог ПК /computers
    Детальная страница ПК /computers/:id
    Личный кабинет /profile
    Бронирование /booking
    Акции(скидки, тарифы, клубная карта) /offers
    Турниры /events

; Frontend: Vue.js, Vue router
; Backend: Node.js
; Database: MySQL

;  Схема данных и API
    1) Пользователь (User)
      id
      email
      password_hash
      keyword
      name
      created_at
    2) Бронь (Booking)
      id
      user_id
      computer_id
      start_time
      end_time
      status

;    API
      Аутентификация
      Метод  URL  Описание
      POST  /auth/register  регистрация
      POST  /auth/login  вход
      POST  /auth/restore  восстановление пароля
      
;     Компьютеры
        Метод  URL  Описание
        GET  /computers  получить список ПК
        GET  /computers/:id  получить данные конкретного ПК
      
;     Бронирование
        Метод  URL  Описание
        POST  /booking  создать бронь
        GET  /booking/my  мои брони
        DELETE  /booking/:id  отменить бронь
      
;     Акции
        Метод  URL  Описание
        GET  /offers  список акций
        GET  /offers/:id  детальная акция
      
;     Турниры
        Метод  URL  Описание
        GET  /events  список турниров
        GET  /events/:id  детальная страница турнира
